| File | Font | Holds |
|---|---|---|
| `inter-latin.woff2` | Inter, © The Inter Project Authors | Latin |
| `zkg-500.woff2`, `zkg-700.woff2` | Zen Kaku Gothic New, © Yoshimichi Ohira | Only the Japanese characters used on /sumi/, plus kana |
| `nunito-sumi.woff2` | Nunito, © The Nunito Project Authors | "Sumi" |
| `yuji.woff2` | Yuji Syuku, © Kinuta Font Factory | 墨 字 私 |

After adding Japanese text to the pages, rebuild the Zen Kaku Gothic New files with the new characters. Characters a
subset doesn't have fall back to the system font.
