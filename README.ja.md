# Sushil Raj · ポートフォリオ

[English](README.md) · **日本語**

公開中：**[sushilraj.dev](https://sushilraj.dev)**

個人サイトです。ページはリアルタイムの墨のシミュレーション（WebGL2 による Stable Fluids）の上に浮かんでいて、墨はカーソルや指の動きを追います。墨が通った部分では、周りの文字の色が反転します。

## 内容

- **墨:** 5種類の墨（墨 sumi、藍 indigo、緋 ember、極光 aurora、画素 pixels）、穏やかから嵐までのスライダー、任意のフィルムグレイン。画素（Pixels）は墨をピクセルアートとして描き、色は青から海緑色へゆっくり移り変わってまた戻ります。墨の濃い所では小さな光がきらめきます。墨はカーソルや指を追い、クリックやタップで墨が増え、スクロールすると墨がかき混ぜられます。スクロールで舞い上がった墨は一度に現れず少しずつ浮かび上がるので、ちらつきません
- **ライトとダーク:** 最初はライトモードで、墨は紙の上の顔料のように見えます。ダークモードでは墨が光ります
- **パソコンでは:** その下の操作（visit、code、copy）を示す塗りつぶしの矢印カーソル、ポインターが入った所から墨で満たされ、ポインターの方へ少し傾くボタン、ブラウザのスクロールバーの代わりの細いスクロールレール、そして自動で打ち込まれる番号付きのセクションタグ
- **風鈴:** コンタクトのセクションには、three.js で 3D に描いたガラスの風鈴があります。絵付けされた玉、ガラスの舌（ぜつ）、そして短冊。ポインターが周りの空気を動かすと、風鈴が揺れ、短冊がはためき、舌がガラスに当たって鳴ります。クリックすると音が鳴ります。three.js はパソコンでのみ、アイドル時間に読み込まれます
- **スマートフォン:** 縦書きの名前、スワイプのカルーセル、全画面メニュー、墨の設定シートを備えた専用レイアウト。スクロール中の指は軌跡を残しません（代わりにスクロールが墨をかき混ぜます）。上部の墨の上では、横向きに始めたストロークや長押しでページが止まり、指で描くことができます。渦も描けます
- **English と日本語:** 日本語のブラウザでは自動的に日本語で表示され、ボタンでどちらにも切り替えられます
- **日本:** 日本への興味がどこから来たのかについてのセクション。始まりは物語（アニメ、漫画、映画）、音楽、そして神話や神道、民話といった古い物語でした。今も惹かれ続けているのは、言葉、現代の街並みと自然の風景、そして暮らし方とその根にある考え方です。それぞれに漢字があり、画面に入ると上から筆で書かれていきます。まだ日本に行ったことはありません。早稲田大学で学ぶ機会を目指していて、それが初めての日本になる予定です
- **セクション:** 7つのプロジェクト、自己紹介、日本、コンタクト。最後はスシルと読む判子で締めくくられます
- **スクロール:** 墨をかき混ぜるほかに、ページ上部を離れると名前が奥へ沈み、見出しがせり上がり、スキルの列がふわりと現れます

## クレジット

### このサイト独自のもの

コンセプト、デザイン、文章：**Sushil Raj**

- 墨の上に浮かび、墨が通った所で文字が反転するポートフォリオ
- 5種類の墨とそのパレット。青と海緑色の間を移ろう、ディザ調できらめくピクセルアートの「画素」を含む
- スマートフォンのジェスチャー：スクロールする指は墨をかき混ぜ、横向きのストロークや長押しで墨を描く
- ナビバーの仕切りから吊るされたガラスの風鈴。絵付けの玉、舌、短冊、そしてポインターの風による揺れ方
- 日本というテーマ：その由来を語るセクション、二か国語のセクションタグ、カタカナの名前、ページを締めくくる判子、そしてタブの「またね」
- サイト上のすべての文章（英語と日本語）

### 基にしたもの

- 墨は Jos Stam の *Stable Fluids* 法（[SIGGRAPH 1999](https://www.dgp.toronto.edu/public_user/stam/reality/Research/pdf/ns.pdf)）による流体シミュレーションで、*GPU Gems* 第38章（[Mark Harris, 2004](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-38-fast-fluid-dynamics-simulation-gpu)）の方法で GPU 上で動かしています。ブラウザでの実装には [Pavel Dobryakov の WebGL Fluid Simulation](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation) を参考にしました。
- ライブラリ：[GSAP](https://gsap.com) と ScrollTrigger、[Lenis](https://github.com/darkroomengineering/lenis)、[three.js](https://threejs.org)
- フォント：Geist と Geist Mono、Instrument Serif、Unbounded、Shippori Mincho B1、Zen Kaku Gothic New、M PLUS 1（すべて [Google Fonts](https://fonts.google.com)）
- 風鈴は実際のガラスの風鈴の写真を基に作りました。判子、短冊、青海波の模様は日本の伝統的なデザインです。

## 実行方法

ビルド不要の静的な単一ページです。`index.html` を開くか、フォルダーをサーバーで配信してください：

```
python3 -m http.server 8000
```

GSAP、ScrollTrigger、Lenis、three.js は CDN から、フォントは Google Fonts から読み込まれます。
