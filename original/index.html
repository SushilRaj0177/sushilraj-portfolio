JADENJapanese address normalization

Reads messy Japanese addresses and returns clean, structured ones. Runs offline with no dependencies.

  • Checks against 1,918 official municipality records
  • Says when an address is ambiguous instead of guessing
  • 222 tests on Python 3.10 to 3.13
